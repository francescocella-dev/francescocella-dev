## Engineering principles

1. Understand the problem before choosing the solution.
2. Prefer simple systems whose behaviour can be explained.
3. Make data flows, assumptions, and trade-offs explicit.
4. Use AI to improve both speed and quality, never as a substitute for understanding.
5. Treat documentation, testing, and maintainability as part of the product.
